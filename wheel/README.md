# Dream Wheel · 黄金时刻玫瑰摩天轮

一个在浏览器里实时运行的「白色新维多利亚式花园摩天轮 + 真实感玫瑰花环」场景（three.js r160，无外部 CDN）。

## 打开方式 / URL

- **主地址：http://127.0.0.1:7811/index.html**
- 兼容旧地址（已同步更新）：http://127.0.0.1:7810/index.html

> 如果页面打不开：在本文件夹打开 PowerShell，运行
> `python -m http.server 7811 --bind 127.0.0.1`
> 然后浏览器访问上面的主地址。也可以双击 `启动.bat`。

建议使用 Chrome / Edge，窗口 ≥ 1280×800；首次加载需读取 HDRI 天空（约 5 MB），约 1–2 秒。

## 最新优化（本轮）

- **花环整圈开满**：取消"顶部厚、底部薄"的旧密度衰减，改为均匀且略偏顶部加厚的分布；新增底层填充花，白天/夜晚从任意角度看，整圈轮辋都有密集玫瑰（不再只有上面几段有花）。
- **花瓣与花瀑缩短**：玫瑰花瓣长度缩短约 10–15%、更宽更圆；垂挂花瀑由 6.6–8.8 单位缩短到 3.6–4.9 单位；漂浮花瓣改为更圆更小，整体更精致。
- **结构细节更多、更立体**：轮辋增加 500+ 颗铆钉/螺栓、24 块铸铁节点板与 24 枚黄铜圆饰；辐条新增 4 道铆接铜箍（每个接头都有金属环）；轮毂新增 48 颗螺栓、黄铜环与中心铜章；吊舱新增穹顶放射肋、三道船体接缝环、四面拱形门框、底部龙骨与支架；塔架构件也补充了铜饰。
- **夜间花环照明增强**：新增两组暖粉补光与更密的轮辋灯串，夜景中整圈花环都能被灯光照出粉/奶白色，而不是只有顶部亮。
- 性能仍然稳定：RTX 5060 实测 **180 fps**（1500×950 全后期，花环约 86 万三角形 / 19 draw calls）。

## 这次做了什么（只重做摩天轮本体，页面外壳与交互保留）

**1. 摩天轮结构（全部重建，按真实结构比例）**
- 两片平行桁架轮辋（外圈/内圈/中圈 + 128 段 X 形斜撑 + 64 根径向肋），前后轮辋之间 24 组箱型横撑与斜拉杆，轮盘有真实厚度。
- 每侧 32 根直辐条（前后相位错开），0.55R / 0.78R 两道拉结环 + 斜拉索、节点块。
- 车轮中心：轮毂鼓身、双面法兰、黄铜放射状饰条、轴承盖与玫瑰花饰。
- 两座 A 字形方管格构塔（三弦杆 + 交叉缀条 + 8 道 X 撑 + 水平系梁 + 平面斜撑 + 黄铜奖章 + 铜靴 + 尖顶饰），约束在轮盘两侧 `z = ±2.35`，绝不穿透轮面。
- 底部石质基座 + 三级台阶 + 黄铜包边/奖章 + 四盏暖光庭园灯；基座周围是玫瑰花坛。
- 24 个玻璃吊舱：车削成型的船形底 + 大面积玻璃观景带（20 根黄铜竖框、3 道铜带）+ 浅椭圆穹顶 + 黄铜轭架/横担/夹箍；每个吊舱每帧做反向旋转补偿，**永远保持竖直**；内部有深色内芯与暖光小灯。

**2. 玫瑰花环（先前版本最缺的部分）**
- 程序化分层玫瑰（13 瓣主花 / 9 瓣中距 / 8 瓣远景三档 LOD，平滑法线 + 卷边 + 花心渐变），另有花苞、叶片、四叶簇、地面花瓣。
- 连续花环带宽约 1.2 单位、中心半径 ≈19.6，包住前后两片轮辋；顶部厚、底部薄，色彩以奶油白/腮红/浅粉为主，深玫瑰只作点缀。
- 轮毂正面 132 朵玫瑰花球；下缘 7 条根重梢轻的垂挂花瀑（随轮旋转但保持世界竖直）；基座前缘与两侧连续玫瑰花坛。

**3. 环境与电影感**
- Poly Haven CC0 纯净天空 HDRI（`kloofendal_48d_partly_cloudy_puresky`），旋转/调色后与场景主光对齐；PMREM 环境反射。
- 暖金主光 + 天空冷补光 + 花丛粉色反弹 + 冷粉轮廓光，2048 阴影贴图。
- 程序化石板广场、远景公园树篱/花园地平线、暖雾、太阳辉光。
- 后期链路：GTAO → UnrealBloom → Bokeh DOF → OutputPass(ACES) → SMAA → 自定义调色（暗角/分离色调/胶片颗粒/边缘色散）。
- 漂浮花瓣、金色尘埃、远处飞鸟；花瓣/尘埃已调低到不影响主体的密度。

**4. 昼夜切换（新增）**
- 面板新增整行按钮 **「🌙 切换夜景 · 烟花」**：点一下，白天会在约 2 秒内平滑过渡成黑夜。也可以按键盘 `N`，或直接双击画面切换。
- 夜晚：深蓝星空 + 1,900 颗星星 + 带光环的月亮；摩天轮 1,300+ 颗暖金/玫瑰色灯珠（轮辋、辐条、轮毂、塔架、基座灯串）发光，吊舱玻璃透出暖光；地面与远景切换为月光蓝灰色调。
- 烟花：在摩天轮上空与两侧绽放，金/玫瑰/奶油/薰衣草/冰蓝色，带拖尾与闪光，随重力下坠、渐隐；每 1–2 秒一发，多朵同时绽放。
- 深链参数：`?night=1` 直接以夜景打开（截图/演示用），`?night=0.5` 可停在过渡中间。

**5. 交互（保留旧版全部按钮，并修复）**
- 暂停旋转 / 复位视角 / 自动环绕 / 结构分解 / 花瓣粒子 / 全屏 + 旋转角度滑杆。
- **切换夜景 · 烟花**：点一下进入黑夜（或按 `N` / 双击画面），再点一下回到白天。
- 「结构分解」会把前后轮辋、辐条层、吊舱、花环沿轴向/径向拉开，方便看清分层构造。
- 鼠标拖拽旋转、滚轮缩放、右键平移；URL 参数支持 `?angleDeg=12&ui=0&quality=low` 等，方便出图。

## 已知限制

- 这是实时程序化场景，不是离线渲染/AI 生图；极近特写下中景 LOD 花瓣仍能看到多边形边缘（主相机机位不可见）。
- 花环为程序化玫瑰，不同角度光照下颜色会偏干/偏暖；如需更艳的粉，可调 `prompts/` 中的材质/光照提示词重新生成参考。
- GTAO/DOF 为高画质耗性能项；低配设备可在 URL 加 `?quality=low`（关闭 AO/DOF/颗粒）。
